장기보유 코인

여기에 등록한 코인은 자동매매 대상에서 완전히 제외됩니다. 매일 아침 스캔에서 후보로 뽑히지 않고, 전량 청산·강제 청산에서도 보호됩니다.
잠금 수량을 0 으로 두면 보유 전량이 보호되고, 양수로 두면 그 수량만 보호하고 초과분은 트레이딩에 사용합니다.

계좌 보유 자산 (미등록)

계좌에는 있지만 아직 장기보유로 등록되지 않은 코인입니다. 클릭하면 바로 등록됩니다.

업비트 API 키

업비트 → 마이페이지 → Open API 관리에서 발급한 키를 입력하세요. 키는 data_store/ 아래에 암호화되어 저장되며 화면에는 마스킹된 값만 표시됩니다.
자산조회·주문 권한과 서버 IP 허용 등록이 필요합니다.

거래 모드

기본값은 모의(paper) 입니다. 실거래로 전환하면 실제 자금으로 주문이 나갑니다. 전환하려면 확인 문구 I-UNDERSTAND 를 입력해야 합니다.
